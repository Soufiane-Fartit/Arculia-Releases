# Arculia for Windows

Installers and updates for Arculia on Windows.

To install, download **ArculiaApp-win-Setup.exe** from the [latest release](https://github.com/Soufiane-Fartit/Arculia-Releases/releases/latest) and run it. Arculia installs for your Windows user only, starts with Windows in the tray, and updates itself from this page.

To uninstall, use Settings › Apps. Your data stays on the PC.
